---
title: "Nodeware"
description: "Steps for common integrations"
---

1. Go to Accounts \> Integrations and enable Nodeware

   ![Enable Nodeware under Accounts > Integrations](/images/nodeware/nodeware-1.png)
2. Enter the Nodeware API key and save

   ![Enter the Nodeware API key and save](/images/nodeware/nodeware-2.png)
3. Open the client in Nodeware and click on Manage Customer

   ![Open the client in Nodeware and click Manage Customer](/images/nodeware/nodeware-3.png)
4. Copy the Customer ID shown in the sidebar

   ![Copy the Customer ID from the sidebar](/images/nodeware/nodeware-4.png)
5. On the Risk Assessment for the same client, enable Nodeware by visiting Setup \> Optional Steps \> Connect Nodeware and adding the customer ID.

   ![Connect Nodeware and add the Customer ID under Setup > Optional Steps](/images/nodeware/nodeware-5.png)
6. Once done, we will start fetching data, and it should show up under Security \> Network in 24 hours
