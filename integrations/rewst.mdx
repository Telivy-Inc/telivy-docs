title: "Rewst"
description: "Integrating Telivy + Rewst"
---

1. Set up a custom configuration - call it Telivy

   ![Set up a custom configuration named Telivy](/images/rewst/rewst-1.png)
2. In Authentication Method, add _api-v1.telivy.com_ as "Hostname" and choose API Key

   ![Add api-v1.telivy.com as Hostname and choose API Key](/images/rewst/rewst-2.png)
3. Navigate to the Telivy portal and look under Account \> Integrations to find your Telivy API key.

   ![Find your Telivy API key under Account > Integrations](/images/rewst/rewst-3.png)
4. In Authentication Details, enter your team's Telivy API key.

   ![Enter your Telivy API key in Authentication Details](/images/rewst/rewst-4.png)
5. In Test Configuration, set up _/api/v1/security/risk-assessments_ as your Test Action URL Path

   ![Set the Test Action URL Path in Test Configuration](/images/rewst/rewst-5.png)
6. Start configuring your workflow\!

   ![Start configuring your workflow](/images/rewst/rewst-6.png)
