Insights is the first screen you land on after logging in. The Assessments list shows you
everything; Insights answers a narrower question. Across the whole book of clients, what
needs you today?

<Note>
  Insights is marked as a preview in the portal, and the team is still collecting feedback
  on it.
</Note>

## Scope toggle

The selector at the top switches everything on the page between **All assessments**,
**External scans**, and **Risk assessments**. One recommended action ignores it, noted
below.

## Security posture

A status breakdown of the assessments in scope (complete, in progress, not started,
archived), plus coverage rows for the cloud connections that matter:

- Microsoft 365 connected
- M365 security policies configured
- Google Workspace connected

Coverage is how you catch the client whose assessment finished but only tells half the
story, because nobody ever connected a cloud account.

## Recommended actions

What to fix, ranked by how much it matters rather than by when it happened. Telivy raises
five:

| Action | Raised when |
| --- | --- |
| Reconnect cloud integrations | A Microsoft 365 or Google Workspace connection lost authorization and stopped collecting |
| Configure Microsoft 365 security policies | M365 is connected but no policy baseline exists |
| Review unread alerts | Any alert is unread |
| Finish incomplete assessments | An assessment never got past setup |
| Put more assessments into monitoring | Assessments exist that aren't being re-scanned |

Each carries a count and a link into the already-filtered list, so "Configure Microsoft 365
security policies" opens the assessments narrowed to exactly those clients.

<Note>
  The monitoring action counts across the whole agency rather than per type, so it only
  shows up while the scope is **All assessments**.
</Note>

## Top opportunities to improve security posture

This one is about score movement, not alerts. Telivy takes the remediation actions from
each assessment, groups the same finding across clients, and ranks those groups by combined
projected impact. It reads as: fix this, at these five clients, and the portfolio gains
roughly this much.

<Warning>
  The calculation runs on demand across your active assessments and stops at the first 25.
  On a large book, treat it as a strong sample rather than a complete ranking.
</Warning>

## Needs attention, recent alerts, and recent activity

The lower half is the working list. Assessments flagged with a reason (cloud needs re-auth,
no M365 policies) come first, worst first, followed by the latest alerts across all clients
and a feed of recent activity.
