## Uninstallation

### How to uninstall Telivy on your Windows Asset

Uninstallation removes the Telivy scanner on the device but the *data gathered during the latest scan still remains on the portal* and is part of the Risk Assessment dashboard and any report generated.

You can uninstall directly from the dashboard using the **Uninstall** button for *each asset* or you can *uninstall all the devices* at once by clicking on the **Uninstall All** button.

### What happens when you click Uninstall

Uninstalling is scheduled, not instant. Clicking **Uninstall** flags the device for uninstall, and the agent applies that flag the next time it runs. The device does not need to be online at the moment you click.

While the flag is waiting to be picked up, the device shows a status of **Uninstall Scheduled**. That status is your notification: it means the instruction is set but the device has not acted on it yet.

The agent runs its cycle roughly every hour, so a device that is reachable should move off **Uninstall Scheduled** within about an hour of coming back online.

<Warning>
A device stuck on **Uninstall Scheduled** for much longer than that, say a few hours to a day, usually means the flag is never reaching the machine: the Telivy Agent Service is not running, or the device cannot connect to Telivy. Uninstall those manually using the commands below.
</Warning>

### Uninstalling a device manually

For a device that never picks up the scheduled uninstall (or any device where you would rather not wait), run the uninstall command directly on the machine, either at the terminal or pushed through your RMM. There are two options, and they have very different effects on the data already collected from that device, so pick deliberately.

#### Option 1: Standard Uninstall (Recommended)

Best for routine removal. This preserves the device's local PII database, so if Telivy is reinstalled later the next scan is faster. Usable since agent version 30.0.0.0.

Run the following command as Administrator:

```powershell
& "C:\Program Files (x86)\Telivy\Telivy Agent\Telivy.Scanner.Windows.exe" --IsUninstallMode=true
```

#### Option 2: Full Wipe

Use this for complete data removal, or to uninstall legacy agent versions (below 20.0.0.0).

<Warning>
This action is destructive. It removes all Telivy history **and the PII database** from the local machine. Only use Full Wipe if you want to get rid of Telivy entirely or you're fixing a corrupted installation. If you might reinstall later and want to keep the existing PII data, use Standard Uninstall instead.
</Warning>

Run the following in PowerShell as Administrator, replacing `<DEEPSCAN_ID>` with the assessment's Deep Scan ID (found on the assessment's configuration page):

```powershell
Invoke-Command -ScriptBlock ([scriptblock]::Create([System.Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://install.telivy.com/uninstall-all.ps1')))) -ArgumentList @('<DEEPSCAN_ID>', '')
```
