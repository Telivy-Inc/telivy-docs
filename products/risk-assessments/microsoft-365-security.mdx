## Requirements

To get login and security data from M365, a Microsoft Entra ID P1 (NCE) license and Global admin is required. This license allows us to retrieve and monitor login statistics like location and MFA status from Microsoft. This license comes with audit logging which enables us to monitor M365 security. Check out plans, cost, and features [here](https://www.microsoft.com/en-us/security/business/microsoft-entra-pricing).

## Configuration

To configure the M365 security, go to your Risk Assessment > Configuration > Configure Microsoft 365 and follow the steps to connect your M365 admin account. Make sure you have the required licenses as described in the previous sections.

<img alt="Microsoft 365 configuration screen in a Telivy risk assessment" src="/images/microsoft-365-security/microsoft-365-security-1.jpg" />

To refetch the data, you can refresh the data from Assets > Softwares > M365 Security and refetch the data as needed.

<img alt="Refetching Microsoft 365 data from Assets, Softwares, M365 Security" src="/images/microsoft-365-security/microsoft-365-security-2.png" />

Telivy helps you manage your Microsoft 365 security posture with dashboards and reports. This article covers three areas Telivy supports for M365 and how to configure the M365 section along with the requirements.
