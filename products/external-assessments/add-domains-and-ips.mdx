---
title: Add Domains and IPs
description: 'Scan additional domains, subdomains, and IP addresses in an assessment'
---

An assessment starts with the single domain you entered when you created it. Most
companies have more exposure than that: a marketing site on another domain, a VPN
endpoint, a mail gateway, a block of static IPs. Add them as targets and they are scanned
alongside the original domain.

## Add a target

<Steps>
  <Step title="Open the assessment's Targets view">
    In the assessment, go to **Targets**. The table lists every target with its type,
    scanning status, when it was last scanned, and how many findings it has.
  </Step>
  <Step title="Click Add Target">
    Choose the target type: **IP Address**, **Domain**, or **Subdomain**.
  </Step>
  <Step title="Enter the values">
    Type it into **Value**, or paste several separated by commas. Telivy checks the format
    first, so a malformed address or domain gets rejected rather than saved.
  </Step>
  <Step title="Click Add Target to save">
    The new targets appear in the table and get picked up by the next scan.
  </Step>
</Steps>

<Note>
  Re-adding a target that's already there changes nothing. The portal says it's already
  added, and no duplicate appears.
</Note>

If **Add Target** is unavailable, the account needs upgrading for extra targets. Email
[accounts@telivy.com](mailto:accounts@telivy.com).

## What to add

- Every domain the company owns, including ones that only redirect
- Subdomains that resolve to something reachable: `vpn.`, `mail.`, `remote.`, `portal.`
- Static IP addresses for on-premise firewalls, VPN concentrators, and mail servers

Each target is scanned for the same things as the primary domain, so open ports and
certificate problems on a forgotten subdomain show up in
[the same findings](/products/external-assessments/overview).
