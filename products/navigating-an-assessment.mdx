Open an assessment and a tab rail runs down the side. Which tabs you get depends on the
assessment type, so an External Scan shows a deliberately shorter set than a Risk
Assessment.

## The tabs

| Tab | What it is for |
| --- | --- |
| **Setup** | Deploy the agent, connect Microsoft 365 or Google Workspace, add targets, configure the scan |
| **Overview** | The headline result: score, top findings, what changed |
| **Inventory** | What Telivy found: devices, network targets, installed software |
| **Security** | The findings themselves, grouped by section, with evidence on each one |
| **Cloud** | SaaS posture for connected Microsoft 365 and Google Workspace accounts |
| **Compliance** | Findings mapped to the CIS Critical Security Controls |
| **Register** | The risk register for the assessment |
| **Reports** | Generate client-ready reports, or upload your own documents |
| **Alerts** | Alerts raised for this client |
| **Company** | Company details and contacts |
| **Services** | Services offered to this client, unless your agency uses its own branding |

**Risk** and **Priorities**, which chart risk over time and rank findings across
severities, appear once prospect monitoring is available to your account. **Trends** only
shows up while the assessment has monitoring enabled.

## The Cloud tab

Cloud is Risk Assessment only. On an External Scan it reads "Not enabled" and gives you a
contact address, because there's no agent and no cloud connection to read from.

Sub-views appear as connections are made, so an assessment with only Microsoft 365
connected won't show Google Workspace at all:

- **Microsoft 365** for secure score, MFA coverage, and login monitoring on the tenant
- **M365 Policy Management** for the policy baseline and where the tenant drifts from it
- **Sharing Risks** for Exchange, SharePoint, and OneDrive exposure, where your account has it
- **Google Workspace** for the same posture view on a connected Workspace domain

An empty tab means nothing is connected. Connect an account under **Setup > Cloud** and the
views turn up on the next data refresh.

## What an External Scan shows instead

No endpoints means a shorter rail: Setup, Overview, Security, Company, Register, Reports,
and Alerts. Anything that depends on the agent or a cloud connection is absent by design,
not missing.
